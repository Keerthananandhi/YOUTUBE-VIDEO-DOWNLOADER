# YouTube to MKV & AA3 Transcoder

### Running locally
1. Ensure Python 3.10+ and ffmpeg are installed on your machine.
2. Install requirements: `pip install -r requirements.txt`
3. Start backend: `uvicorn app:app --reload --port 8000`
4. Open `index.html` in your browser.

### Hosting Online for Free
- **Backend**: Deploy this repository or folder on [Render.com](https://render.com) using the included `Dockerfile` (Web Service, Free Tier).
- **Frontend**: Drag and drop `index.html` into [Netlify Drop](https://app.netlify.com/drop).
